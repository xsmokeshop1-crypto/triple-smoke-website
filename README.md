# Triple Smoke Shop website
Responsive static HTML/CSS/JS site for GitHub Pages. No build step required.
## Edit the site
Most owner-editable content is in the SITE_CONFIG block at the top of script.js.
- Change headline and subhead to update the hero.
- Add the real address, hours, phone and verified social URLs.
- Edit collections and products; replace sample products with real inventory before setting verified:true.
- Upload product photography to assets/ and set the matching image path in the configuration.
- Replace the logo asset at assets/triple-smoke-logo.webp only with your real logo file.
- Keep CNAME and favicon.svg when publishing.
## Publish
Commit changes to main, then check the Actions tab for a successful GitHub Pages deployment. Hard-refresh triplesmoke.shop after deployment. Confirm the age notice language and age limit comply with applicable local rules.
